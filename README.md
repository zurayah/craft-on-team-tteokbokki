# craft-on-team-tteokbokki

# 요시와라
> 환락가 '요시와라', 그곳에서 감지된 미확인 마법을 조사하는 1인칭 마법 추리 어드벤처 게임

## 팀원 소개
| 이름 | 역할 | GitHub |
| :---: | :---: | :---: |
| 김현하 | 1인 개발 | [@zurayah](https://github.com/GitHub아이디) |

## 게임 소개
- **장르**: 1인칭 미스터리 추리 / 방탈출 어드벤처
- **배경 및 스토리**:
  - 플레이어는 **왕립 마도 기록원 산하 '미등록 마법 수집국'** 의 신입 현장 수집관이 되어, 몇 달 전 심야에 유곽 내부에서 일시적으로 계측된 미확인 마법 파장의 정체를 규명하기 위해 파견됩니다.
- **재미 포인트**:
  - 벼락치기로 만들어서 굉장히 조잡합니다. 너무 열내진 마시고 막히면 꺼주시면 감사하겠습니다... 
  

## 조작법
| 키 / 입력 | 동작 |
| :---: | :--- |
| **W, A, S, D** | 이동 |
| **E** | 상호작용 |
| **마우스 휠** | 문서 본문 스크롤 |
| **J** | 현장 조사 파견 지령서 다시 보기 / 닫기 |
| **K** | 보고서 작성 창 열기 / 닫기 |
| **ESC** | 시스템 메뉴 |

## 다운로드
[게임 다운로드 (v1.0)](https://github.com/zurayah/craft-on-team-tteokbokki/releases/tag/v1.0)

## 실행 방법
1. 위 다운로드 링크(Releases)에서 `.zip` 압축 파일을 다운로드합니다.
2. 압축을 해제한 폴더 안에서 **`yoshiwara_demo.exe` 실행 파일**을 더블클릭하여 실행합니다.
   - *(주의: `.exe` 파일만 따로 바탕화면 등으로 빼내면 실행되지 않으니, 반드시 압축을 푼 폴더 내부에서 실행해 주세요.)*
