# 요시와라
> 환락가 '요시와라', 그곳에서 감지된 미확인 마법의 진실을 파헤치는 1인칭 마법 추리 어드벤처 게임

## 팀원 소개
| 이름 | 역할 | GitHub |
| :---: | :---: | :---: |
| [본인 이름] | 1인 개발 (기획 / 프로그래밍 / 레벨 디자인) | [@GitHub아이디](https://github.com/GitHub아이디) |

## 게임 소개
- **장르**: 1인칭 미스터리 마법 추리 / 방탈출 어드벤처 (3D First-Person Mystery Adventure)
- **배경 및 스토리**:
  - 하늘을 거대한 강철 돔으로 덮어 365일 인공 마나석 조명만이 빛나는 특별 환락구 **'요시와라'**.
  - 플레이어는 **왕립 마도 기록원 산하 '미등록 마법 수집국'** 의 신입 현장 수집관이 되어, 며칠 전 심야에 유곽 내부에서 일시적으로 계측된 미확인 마법 파장의 정체를 규명하기 위해 파견됩니다.
- **재미 포인트**:
  - **문서와 현장 단서를 엮어가는 교차 추리**: 유곽 사람들의 일기장, 숙박 대장, 당번 명부, 불만 쪽지, 신문 칼럼 등 파편화된 기록을 대조해 그날 밤의 사건과 숨겨진 공간을 추적합니다.
  - **한정된 자원과 환경 기믹 활용**: 건물 전체의 전등을 밝히는 단일 배전판의 **마나석**과, 보이지 않는 마력 공백 지대('세상의 빈틈')에서 불씨가 꺼지는 **물담배**를 활용해 눈에 보이지 않는 마법 잔상의 위치를 직접 탐지합니다.
  - **마도구 집광 및 3단계 마법진 해독**: 회수한 미확인 마도구에 마나석을 장착하고 푸른 빛을 집광하여, 현장에 남겨진 3단계 기하학 문양 암호를 직접 그려 넣음으로써 그날 밤의 마법을 재현합니다.
  - **직접 작성하는 서술형 결과 보고서 엔딩**: 정해진 선택지를 고르는 대신, 플레이어가 스스로 규명한 마도구의 이름·시전 방식·마법 효과·위험도를 직접 서술하여 세상에 하나뿐인 최종 조사 보고서를 완성합니다.

## 조작법
| 키 / 입력 | 동작 |
| :---: | :--- |
| **W, A, S, D** | 이동 |
| **마우스 이동** | 시점 회전 |
| **E** | 상호작용 (문서 읽기 / 물건 줍기 / 마나석 장착 및 분리 / 문·서랍 열기) |
| **G** | 손에 든 물건 내려놓기 |
| **마우스 우클릭 (홀드)** | 손에 든 도구 사용 (물담배 흡입 / 마도구 빛 모으기 및 마법진 그리기) |
| **마우스 휠 / 방향키(↑, ↓)** | 문서 본문 스크롤 |
| **J** | 현장 조사 파견 지령서 다시 보기 / 닫기 |
| **K** | 미확인 마법 장치 회수 보고서 작성 창 열기 / 닫기 |
| **ESC** | 닫기 / 시스템 메뉴 (처음부터 다시 시작 / 게임 종료) |
