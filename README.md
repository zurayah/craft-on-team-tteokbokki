# 요시와라 (Yoshiwara)

**《요시와라》** 는 플레이어 스스로 기록을 대조하고 마법의 작동 원리를 추론해 진실에 도달하는 **1인칭 미스터리 추리 어드벤처** 게임입니다.

## 게임 소개

- **장르**: 1인칭 미스터리 추리 어드벤처

### 미등록 마법 수집국에 오신 것을 환영합니다!
당신이 살아가는 이 도시는 마법이 신비로운 기적이 아닌, 차가운 행정과 기술로 관리되는 회색빛 디스토피아입니다. 도시는 '마나석'을 태워 돌아가는 마도 배관과 인공 조명으로 차갑게 빛나고, 국가 기관인 왕립 마도 기록원은 세상의 모든 마법을 규격화하여 통제합니다. 이곳에서 등록되지 않은 마법은 그 자체로 체제를 위협하는 불법이자 불온한 오점으로 취급받습니다.

그런 통제된 도시의 가장 깊고 어두운 그늘에 홍등가 '요시와라'가 자리 잡고 있습니다. 밤마다 화려한 등불과 물담배 연기, 사람들의 욕망과 한숨이 뒤엉키던 이 거대한 목조 유곽은, 역설적이게도 도시에서 가장 인간적인 감정이 밑바닥까지 드러나는 공간이었습니다. 그러나 몇 달 전 심야, 유곽 내부에서 출처 불명의 마법 파장이 일시적으로 계측된 그날 밤 이후 화려했던 유곽은 모든 불이 꺼진 채 차가운 봉쇄선 너머에 갇혀 버렸습니다.

당신은 **왕립 마도 기록원 산하 '미등록 마법 수집국'** 에 새로 배속된 신입 현장 수집관으로서 이 봉쇄된 유곽에 파견됩니다. 이곳에서 무슨 일이 벌어졌든 기관의 명령은 단 하나뿐입니다. 어둠 속에 잠긴 유곽을 수색해 **미확인 마법 장치를 회수하고, 그 발동 조건과 효과를 판별하여 보고서를 제출**하십시오.

### 게임플레이: 지식이 곧 열쇠가 되는 추리
《요시와라》는 퀘스트 마커나 친절한 힌트 시스템으로 플레이어의 손을 잡고 이끌지 않습니다. 플레이어는 실제 현장 조사관처럼 건물의 전력을 복구해 공간을 확보하고, 남은 기록들을 직접 대조하며 사건의 재구성에 나서야 합니다.

단순히 문서를 읽는 데서 끝나지 않습니다. 남겨진 기록이 과연 사실인지, 그 안에 적힌 단서가 실제 현장과 어떻게 맞물리는지 두 눈으로 직접 확인하고 검증해야만 감춰져 있던 진실에 다가설 수 있습니다.

### 주요 특징
- **가이드 없는 자율적 현장 수사**: 화살표나 목표 표시 없이, 1층부터 4층까지 이어진 유곽 내부를 자유롭게 탐색하며 단서와 단서 사이의 빈칸을 플레이어 스스로의 추론으로 메워 나갑니다.
- **환경과 맞물리는 마법 법칙**: 마법은 저절로 일어나지 않습니다. 현장에 남겨진 사물들의 물리적 반응을 관찰하고 조작하여 마법이 발현되는 조건을 직접 찾아내야 합니다.

### 📌 수사를 시작하기 전에
- 본 게임은 별도의 힌트나 자동 기록 시스템을 제공하지 않는 하드코어 추리물입니다. 원활한 사건 재구성을 위해 **스크린샷과 메모장**을 준비해 주시길 권장합니다.

## 조작법
| 키 / 입력 | 동작 |
| :---: | :--- |
| **W, A, S, D** | 이동 |
| **E** | 상호작용 |
| **마우스 휠** | 문서 본문 스크롤 |
| **J** | 현장 조사 파견 지령서 보기 |
| **K** | 보고서 작성 창 열기 |
| **ESC** | 시스템 메뉴 |

## 실행 방법
위 다운로드 링크에서 사용 중인 운영체제에 맞는 압축 파일을 다운로드해 주세요.

### 🪟 Windows
1. **`yoshiwara_demo_wins.zip`** 파일을 다운로드하고 압축을 해제합니다.
2. 압축을 푼 폴더 내부의 **`yoshiwara_demo.exe`** 파일을 더블클릭하여 실행합니다.
   - *(주의: `.exe` 파일만 따로 바탕화면 등으로 빼내면 실행되지 않으니, 반드시 압축을 푼 폴더 내부에서 실행해 주세요.)*

### 🍎 macOS
1. **`yoshiwara_demo_mac.app.zip`** 파일을 다운로드하고 압축을 해제합니다.
2. 압축을 풀어 생성된 **`yoshiwara_demo.app`** 파일을 실행합니다.
   - *(참고: "확인되지 않은 개발자" 경고가 뜰 경우, 앱 아이콘을 **우클릭(Control + 클릭) → 열기**를 선택하시면 정상적으로 실행됩니다.)*
